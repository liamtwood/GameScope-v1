# GameScope Mobile App

Add a mobile app to the existing **GameScope** Replit project — a sports club management platform for youth football clubs.

---

## Architecture

**Do not create a new backend.** This mobile app shares the existing backend:
- **Database:** PostgreSQL (already set up)
- **API:** Node.js / Express (already running in this project)
- **Auth:** Use the existing auth mechanism (JWT or session) already in place

**Frontend:** Add a `/mobile` folder to this Replit project using **Capacitor** (preferred, since the project already uses React and Tailwind) or React Native. Reuse existing API calls and data models wherever possible.

All data shown in the mobile app should be fetched from the existing Express API endpoints. Where an endpoint doesn't exist yet for a mobile-specific need, add it to the existing Express router — do not create a separate server.

---

## Tech Stack (Mobile Frontend)
- React + Capacitor (shares existing React/Tailwind codebase)
- Tailwind CSS — reuse existing config
- Fetch data from existing `/api/...` Express routes
- Local UI state only where needed (e.g. form inputs, tab selection)

---

## Design Guidelines
- Mobile-first, card-based UI
- Primary colour: green (`#16a34a` / Tailwind `green-600`)
- Clean white cards with subtle `gray-100` backgrounds
- Small typography throughout (most labels ~9–11px)
- Rounded cards (`rounded-xl`), subtle shadows
- No bottom nav labels need to be large — keep it compact

## Screens & Navigation Flow

```
Club Home → Team Home → Match Hub (tabs: Details / Squad / Result / Video)
Bottom nav: Home → Club Home, You → Player Profile
```

---

## Screen 1: Club Home
The landing screen. Shows the club overview.

**Header (green background):**
- Club badge (circle with initial), club name, season
- Notification bell with badge count
- 3 stat tiles: Total Players, Fixtures This Week, Videos Pending

**Filter row:** All / Boys / Girls / Today

**Team list:** Each team shown as a tappable card with:
- Badge circle, team name, alert badge (red dot with count if applicable)
- Next fixture summary (e.g. "Today 10:00 AM vs Riverside")
- Season record: W / D / L in green / gray / red
- Chevron (→) — tapping navigates to Team Home

**Footer:** "Add new team" dashed card

---

## Screen 2: Team Home
Shown after tapping a team from Club Home.

**Header:** Back arrow, team badge + name + season, notification bell

**Season Record card:** Won / Drawn / Lost / GF / GA / GD in a horizontal row

**Fixtures & Results list:** Each fixture is a tappable full-width card:
- Left coloured stripe: green for upcoming, green/red for W/L
- Opponent name + UPCOMING badge if applicable
- Date, time, venue, competition
- Result badge (e.g. "W 2-0" in green, "L 0-5" in red) for completed matches
- Chevron (→) — tapping navigates to Match Hub

**Footer:** "Add fixture" dashed card

---

## Screen 3: Match Hub
Shown after tapping a fixture. Has a match summary header and four tabs.

**Match summary bar:** Home team badge + name / "vs" + date & time / Away team badge + name

**Tabs:** Details · Squad · Result · Video
- Green dot on tab if that section is complete

### Tab: Details
- Match info rows: Competition, Date, Kick-off, Venue, Format, Duration
- Notes for players (free text block)
- "Edit match details" tappable row

### Tab: Squad
Two sections — **Starters** and **Substitutes** — each as a white card.

Each player row shows:
- Position badge (colour-coded: GK=yellow, DEF=blue, MID=green, FWD=red)
- Jersey number
- Player name
- Role toggle button:
  - If starter: green pill showing **✓**
  - If sub: gray pill showing **⇄ Sub**
  - Tapping toggles the player between starter and sub
  - Injured players show "Injured" in red and cannot be toggled

Counts update live. Info tip: "Tap a player's role badge to toggle between Starter and Sub."

Confirm Squad button at the bottom.

### Tab: Result
- Orange warning banner if result not yet entered
- Score entry: two +/− stepper controls, one per team
- Expandable rows for: Goal Scorers / Cards / Substitutions
- Save Result button

### Tab: Video
Supports multiple videos. Each video has a URL (link) or phone recording source.

**Saved videos list:**
- Each saved video shows: play icon, truncated URL, footage type badge, camera position badge, ✓ Saved, and an × remove button

**Add video form (inline, toggled by "+ Add another video"):**
- Source toggle: 🔗 Link | 📱 Record
  - **Link:** text input for URL; auto-detects Veo links and shows "✓ Veo link detected"
  - **Record:** dashed box with ⏺ icon, "Start Recording" red button (simulate tap → shows "✓ Video ready")
- Footage type selector: 1st Half / 2nd Half / Full Game / Training
- Camera position grid (2×2): Sideline / Behind Goal / Elevated / Other
- Save Video / Cancel buttons

**Submit button** (only shown when ≥1 video saved): "Submit N Video(s) for Processing"

## Screen 4: Player Profile
Accessed via the "You" tab in bottom nav.

**Green header:** Player avatar (initials), name, jersey + position, team name

**Stats row (4 tiles):** Apps / Goals / Assists / Mins

**Watch Highlights button:** Play icon, "7 clips available", NEW badge

## Data & API

All screens should fetch real data from the existing Express API. Below are the data requirements per screen — map these to existing endpoints or add new ones to the Express router as needed.

| Screen | Data Needed | Suggested Endpoint |
|--------|-------------|-------------------|
| Club Home | All teams for the club, next fixture per team, season W/D/L per team, unread notification count | `GET /api/clubs/:clubId/teams` |
| Team Home | Team details, season record, full fixture list with results | `GET /api/teams/:teamId/fixtures` |
| Match Hub – Details | Fixture details (date, time, venue, competition, format, notes) | `GET /api/fixtures/:fixtureId` |
| Match Hub – Squad | Squad players with role (starter/sub), fitness status | `GET /api/fixtures/:fixtureId/squad` |
| Match Hub – Result | Fixture result, goal scorers, cards, substitutions | `GET /api/fixtures/:fixtureId/result` |
| Match Hub – Video | Videos linked to fixture (URL, footage type, camera position) | `GET /api/fixtures/:fixtureId/videos` |
| Player Profile | Logged-in player's profile, season stats, recent match appearances | `GET /api/players/me` |

**Write operations needed:**
- `PATCH /api/fixtures/:fixtureId/squad` — save starter/sub selections
- `POST /api/fixtures/:fixtureId/result` — submit match result
- `POST /api/fixtures/:fixtureId/videos` — add a video (URL or recorded file upload)
- `DELETE /api/fixtures/:fixtureId/videos/:videoId` — remove a video

If the logged-in user is a **coach**, show squad management, result entry, and video upload. If they are a **player**, show their profile and highlights. Use the existing user role from the auth token to determine this.
