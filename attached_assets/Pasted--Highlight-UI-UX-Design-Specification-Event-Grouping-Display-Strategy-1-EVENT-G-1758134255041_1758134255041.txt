# Highlight UI/UX Design Specification
## Event Grouping & Display Strategy

---

## 1. EVENT GROUPING HIERARCHY

### **Primary Grouping Methods**

#### A. **Temporal Grouping (Timeline View)**
Groups events by time periods and match flow:

```
├── Match Phases (Macro Level)
│   ├── First Half (0-45')
│   ├── Second Half (45-90')
│   └── Extra Time (90-104')
│
├── Action Sequences (Micro Level)
│   ├── Pressure Periods (3+ events in 5 min)
│   ├── Goal Sequences (build-up → goal → reaction)
│   └── Momentum Shifts (possession changes)
│
└── Individual Events
    └── Timestamped moments
```

#### B. **Priority-Based Grouping**
Events categorized by importance:

| Tier | Priority Score | Color Code | Events |
|------|---------------|------------|--------|
| **Must Include** | 80-100 | 🟢 Green | Goals, penalties, red cards |
| **High Priority** | 60-79 | 🟠 Orange | Great saves, near misses, yellows |
| **Supporting** | 25-59 | 🔵 Blue | Chances, skills, tactical moments |
| **Context** | 0-24 | ⚫ Gray | Build-up play, atmosphere |

#### C. **Event Type Grouping**
Categorical organization:

- **Scoring Events**: Goals, penalties, own goals
- **Attempts**: Shots on/off target, blocked shots
- **Defensive**: Saves, clearances, blocks
- **Discipline**: Yellow cards, red cards, fouls
- **Transitions**: Substitutions, injuries
- **Set Pieces**: Corners, free kicks, throw-ins

#### D. **Team-Based Grouping**
Separated by team involvement:

- **Team A Events**: All actions by Team A
- **Team B Events**: All actions by Team B
- **Neutral Events**: Referee decisions, injuries

### **Smart Features**

#### **Auto-Grouping Algorithm**
```python
def auto_group_events(events):
    groups = []
    current_group = []
    
    for event in events:
        if should_start_new_group(event, current_group):
            if current_group:
                groups.append(create_group(current_group))
            current_group = [event]
        else:
            current_group.append(event)
    
    return groups

def should_start_new_group(event, current_group):
    if not current_group:
        return True
    
    # Time gap > 5 minutes
    if event.minute - current_group[-1].minute > 5:
        return True
    
    # Different match phase
    if get_phase(event) != get_phase(current_group[-1]):
        return True
    
    # Significant event (goal, red card)
    if event.priority >= 80:
        return True
    
    return False
```
